## Getting Started

### System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- Microphone (for voice interaction)
- Camera (for video chat)

### Accessing the Application

1. Open your web browser
2. Navigate to the W3J Assistant URL
3. The application will load automatically

### Creating an Account

1. Click the "Sign In" button in the top-right corner
2. Click "Sign Up" to create a new account
3. Enter your email address and password
4. Click "Create Account"
5. Check your email for a verification link
6. Click the verification link to activate your account

## Chat Interface

The chat interface is the main way to interact with W3J Assistant.

### Sending Messages

1. Type your message in the input field at the bottom of the screen
2. Press Enter or click the Send button (paper airplane icon)
3. Wait for the assistant to respond

### Message Types

W3J Assistant can display different types of messages:

- **Text messages**: Regular text responses
- **Structured output**: Formatted information like menu items, recipes, or opening hours
- **Audio responses**: Voice responses that can be played back

### Chat Controls

- **New Chat**: Start a fresh conversation
- **Clear Chat**: Remove all messages from the current conversation
- **Save Chat**: Save the current conversation to your history (requires account)

## Voice Interaction

W3J Assistant supports voice input and output for a hands-free experience.

### Voice Input

1. Click the microphone icon in the input area
2. Speak your question or request clearly
3. Click the stop icon (or wait for automatic detection of speech end)
4. The assistant will process your voice input and respond

### Voice Output

If you have an ElevenLabs API key configured, the assistant can respond with voice:

1. Enable voice output in Settings
2. The assistant will generate voice responses for text replies
3. Control playback using the audio player controls

## File Uploads

You can upload files to provide context or ask questions about their content.

### Supported File Types

- Images (JPEG, PNG, GIF)
- Documents (PDF, TXT)
- Spreadsheets (CSV)

### Uploading Files

1. Click the paperclip icon in the input area
2. Select a file from your device
3. Add any additional text to your message
4. Send the message with the file attached

## Video Chat

For a more interactive experience, you can use the video chat feature.

### Starting Video Chat

1. Click the video camera icon in the header
2. Grant permission to access your camera when prompted
3. The video chat interface will open
4. You can now interact with the assistant while sharing your video

### Video Controls

- **Camera toggle**: Turn your camera on/off
- **Microphone toggle**: Mute/unmute your microphone
- **End call**: End the video chat session

## Web Search

W3J Assistant can search the web to provide up-to-date information.

### Enabling Web Search

1. Go to Settings
2. Enable the "Web Search" option
3. Enter your Brave Search API key (if required)

### Using Web Search

Simply ask questions that might require current information:

- "What's the weather like today?"
- "What are the latest news about AI?"
- "Who won the game last night?"

The assistant will automatically search the web when needed to provide accurate information.

## Menu Assistance

W3J Assistant is specially designed to help with menu-related queries.

### Menu Queries

You can ask about:

- Menu items and categories
- Ingredients and dietary information
- Prices and availability
- Recommendations based on preferences
- Drink pairings

### Example Menu Questions

- "What vegetarian options do you have?"
- "Tell me about your desserts"
- "What wine would pair well with the salmon?"
- "Do you have any gluten-free options?"
- "What are your most popular dishes?"

## User Account

Creating an account allows you to access additional features.

### Account Benefits

- Save chat history
- Sync settings across devices
- Store API keys securely
- Access personalized recommendations

### Managing Your Account

1. Click your profile icon in the top-right corner
2. Select "Dashboard" to access your account settings
3. From here you can:
   - Update your profile information
   - Change your password
   - Manage your API keys
   - Set your preferences

## Chat History

With an account, your chat history is saved automatically.

### Accessing Chat History

1. Click the menu icon in the top-left corner (on mobile) or use the sidebar (on desktop)
2. Your previous conversations will be listed
3. Click on any conversation to continue where you left off

### Managing Chat History

- **Rename**: Click the edit icon next to a chat title
- **Delete**: Click the trash icon to remove a conversation
- **New Chat**: Click the "New Chat" button to start a fresh conversation

## Settings

Customize your experience through the Settings panel.

### API Settings

- **AI Provider**: Choose between different AI providers (OpenAI, Anthropic, GROQ, etc.)
- **Model**: Select the specific AI model to use
- **API Key**: Enter your API key for the selected provider
- **System Prompt**: Customize the initial instructions given to the AI

### Advanced Settings

- **Web Search**: Enable/disable web search capability
- **Voice Settings**: Configure voice input and output options
- **MCP Server**: Configure the MCP server for advanced features

## Accessibility Features

W3J Assistant includes several accessibility features to ensure everyone can use the application.

### Accessibility Options

- **High Contrast**: Increase contrast for better visibility
- **Large Text**: Increase text size for better readability
- **Reduced Motion**: Minimize animations and transitions
- **Screen Reader Mode**: Optimize for screen readers

### Keyboard Shortcuts

- **Alt + C**: Toggle high contrast mode
- **Alt + T**: Toggle large text mode
- **Alt + M**: Toggle reduced motion mode
- **Alt + S**: Toggle screen reader mode
- **Tab**: Navigate through interactive elements
- **Enter**: Activate buttons or links
- **Esc**: Close dialogs or menus

## Language Options

W3J Assistant supports multiple languages.

### Changing Language

1. Click the globe icon in the header
2. Select your preferred language from the dropdown menu
3. The interface will update to display text in the selected language

### Supported Languages

- English
- Spanish
- French
- German
- Chinese
- Japanese
- Arabic

## Troubleshooting

### Common Issues

#### The assistant isn't responding
- Check your internet connection
- Verify your API key is correct
- Try refreshing the page

#### Voice input isn't working
- Check if your browser has microphone permissions
- Make sure your microphone is working
- Try using a different browser

#### File upload fails
- Check if the file is too large (max 10MB)
- Verify the file type is supported
- Try a different file

### Getting Help

If you encounter issues not covered here:

1. Click the "Help" button in the footer
2. Check the FAQ section
3. Contact support through the provided form

## Privacy & Security

### Data Usage

- Chat messages may be stored to provide chat history functionality
- Voice recordings are processed but not stored permanently
- Files are processed but not stored permanently unless explicitly saved

### API Keys

- Your API keys are encrypted and stored securely
- Keys are never shared with third parties
- You can delete your keys at any time

### Account Security

- Use a strong, unique password
- Enable two-factor authentication if available
- Log out when using shared devices
